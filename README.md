# Poseidon for Claude Code

Winning e-commerce ads from Meta's Ad Library, measured. [askposeidon.app](https://askposeidon.app)

```
/plugin marketplace add iolotaro/poseidon-plugin
/plugin install poseidon@askposeidon
```

Paste your key when asked. Free key, 100 credits, no card:

```
curl -X POST https://api.askposeidon.app/v1/keys -H 'Content-Type: application/json' -d '{"email":"you@example.com"}'
```

Then ask: *"Give me a winning format for bloating in Germany, go look."*
